# Chess 47

Mini chess engine for the SwissMicros C47 / R47 calculator (RPN).

Matrix-based board representation, inspired by Micro-Max (H.G. Muller).

Target: DM42n / C47 / R47 firmware with STRUCT, ATEXT and GRFNT.

## Status

- [x] Repository created
- [ ] Board matrix setup
- [ ] Piece encoding (Micro-Max style)
